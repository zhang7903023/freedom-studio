不会编程，但想让想法变成网站，现在真的可以做到。这篇记录我用 AI 编程工具做网站的完整过程。

## 前置条件

只需要三样东西：

1. 一个能用的 AI 编程助手（本文用的是 Codex）
2. 一个代码编辑器
3. 一点耐心，用于描述清楚你想要什么

## 实际过程

### 第一步：说清楚需求

把「我想要一个博客网站」换成具体描述：几个页面、什么风格、要不要深色模式。AI 的输出质量基本取决于你描述的质量。

### 第二步：让它跑起来

安装依赖、启动开发服务器、处理报错——每一步都可以直接把报错贴给 AI：

```bash
npm install
npm run dev
```

### 第三步：部署上线

静态网站推到 GitHub Pages 或 Cloudflare Pages 就能上线，全程不用碰服务器。

## 真实的坑

- 一次别提太多需求，改起来容易乱
- 报错信息要完整复制，不要自己转述
- 先跑通最小版本，再慢慢加功能

整个过程最难的其实不是技术，是把需求想清楚。
